- advanture-camp
- Adventure Camp adalah program penyewaan peralatan camping yang dibuat menggunakan bahasa pemrograman C untuk mempermudah proses penyewaan dan perhitungan biaya. Program ini menyediakan lima jenis peralatan, yaitu tenda, sleeping bag, kompor portable, matras camping, dan lampu camping. Pengguna dapat memilih peralatan, menentukan jumlah unit dan lama penyewaan, kemudian program akan menghitung total biaya serta memberikan diskon sesuai ketentuan. Selain itu, program dapat menampilkan struk pembayaran dan riwayat transaksi dengan kapasitas maksimal 10 transaksi. Dalam pembuatannya, program ini menerapkan fungsi, array, percabangan, perulangan, dan validasi input sebagai penerapan materi algoritma dan pemrograman bahasa C.
